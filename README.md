# naturalflo README

## 1. Setup Instructions

- Clone the repository and open in vscode
- Go to the boiler-plate branch
- Run `npm install` in the terminal to install dependencies
- Then, to run the project, use `npm run dev`

## 2. Important Things To Note:

The illustrated images used here are ONLY temporary. I highly recommend the client find some royalty-free images or take pictures of what they want themselves, ensuring they are a good fit. If these temporary images are used freely, proper credit must be given.

## 3. Features you can show

- The responsiveness of the site is fully functional.
- A "View More" option in the testimonial section appears when the screen size is small.
